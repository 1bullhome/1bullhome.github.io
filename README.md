# 1bullhome.github.io

Home page and privacy policy for **Cathedral Home Assistant**, a private household tool. Google requires these pages for the app's OAuth consent screen.

**Do not delete or rename `googleda7ad5eeb9680e6b.html`.** It proves ownership of this site to Google Search Console. Without it, the site's verification lapses and the Google sign-in setup can break.

The source for these pages is kept in the household's local Cathedral project (`site/`). Edit it there first, then update this repository to match.
